# Thread targets

Ivory #f7f3ea

Hex targets are visual references, not thread SKU codes. Match to the provider’s available palette with a physical swatch. Native 300DPI art; outlined letters add at least 18px (~1.52mm) width at terminals. No letter cap height below 71px (~6mm). Do not reduce; digitization approval/sample required. Patch-shaped embroidery is not a separately sewn patch unless offered by the chosen blank.

Final PNG is quantized to the listed solid thread palette. Enclosed counters smaller than 324px² are filled in matching thread in PNG/SVG to prevent tiny voids.

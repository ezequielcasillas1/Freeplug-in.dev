# Thread targets

## Dark blanks (black, charcoal, navy, dark heather)
File: `front-embroidery-dark-garment.png`
Thread: **Ivory only** `#f7f3ea` (1 color). Same canvas/placement as `printify-ready/standard-thread-front.png` (1650×600).

## Light blanks (white, khaki, etc.)
File: `front-embroidery-light-garment.png`
Thread: **Black only** `#111111` (1 color).

NEVER put the black/light-garment file on a dark blank. NEVER put the ivory/dark-garment file on a light blank.
Native 300DPI; letter strokes embroidery-safe. Digitizer validation required.

# Freeplug Giving-Verses — Tee Designs (v3 large hero)

22 Freeplug tees. Notion FreePlug Cultivation Plan (read-only) + BibleGateway KJV cross-check (kingjamesbibleonline.org timed out).

**Design:** Verse hero ~80–82% print width, 3–6 words/line, bold FP fonts. Motifs large. Ref smaller. FP mark small. Compact centered stack so mockups show ~12in full-front chest.

**Print:** 4500×5400 light/dark garment PNGs. No paid gen / Printify / site / AI mention / street address.
